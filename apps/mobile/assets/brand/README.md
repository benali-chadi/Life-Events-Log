# Life Events Log brand assets

## Concept

The open-loop path represents a life moving through meaningful events, returning near earlier chapters in reflection, and continuing forward. The three rings are events; the quiet arrow is continuation rather than a destination.

## Source files

- `logo-mark.svg`: primary transparent mark for light backgrounds.
- `logo-mark-reversed.svg`: light green mark for dark backgrounds.
- `logo-lockup.svg`: primary mark plus the full `Life Events Log` name.
- `logo-lockup-dark.svg`: full lockup for dark backgrounds.
- `logo-lockup-compact.svg`: compact mark plus the short `LEL` name.
- `app-icon.svg`: full-bleed ivory app-icon master. Do not add rounded corners; platforms apply their own masks.
- `adaptive-icon-foreground.svg`: safe-area Android foreground master.
- `splash-icon.svg`: transparent splash-screen master.
- `native-splash-icon.svg`: symbol-only artwork for Android/iOS system splash constraints.

PNG files in `../images` are generated platform exports. Edit the SVG masters, not the PNGs.

The exact Instrument Sans variable font and its OFL license are stored in `../fonts`. The PNG lockup exports contain the correct rendered type and are safe to use without installing the font.

## Color

- Ink: `#182126`
- Warm ivory: `#FBF6EC`
- Brand green: `#91BFA3`
- Dark-background brand green: `#ACD2B7`

## Typography

- Typeface: Instrument Sans.
- `Life Events Log`: Bold (700), title case.
- `LEL`: Bold (700), tracking tightened by approximately `-0.025em`.
- Splash screens use the mark above the full name only.
- Website headers use the mark beside the full name.
- Tight navigation areas use the mark beside `LEL`.

## Clear space and sizing

- Keep clear space around the mark equal to at least one event-ring diameter.
- Use the full mark at 32 px or larger.
- Below 32 px, use the favicon export with its optically heavier stroke and simplified event centers.
- Never stretch, rotate, close the loop, add another arrow, or place text inside the path.

## Backgrounds

- Use the ink mark on warm ivory, white, and other quiet light surfaces.
- Use the reversed mark on dark surfaces.
- Avoid busy imagery behind the mark unless a solid holding shape provides sufficient contrast.
